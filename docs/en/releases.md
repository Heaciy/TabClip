# All Releases

This page records all version updates of TabClip.

## v0.1.2

> 2025-12-09

### ✨ Features

- Tab Group Categorization: Added support for categorizing tab groups.
- Sidebar Management: Introduced a sidebar for easier category management.
- Tab Whitelist: Added a whitelist to filter tabs that don’t need to be saved.
- Internationalization: Added support for more languages, such as Japanese, Korean, French, Spanish, etc.
- UI & Settings Improvements: Support for restoring default settings, added version notes, and improved UI experience.

### 🐛 Bug Fixes

- Duplicate Rendering: Fixed multiple fetches and duplicate tab groups when loading the first page after custom
  settings.
- Scroll Loading Issue: Fixed data offset issue when loading the next page after deleting a tab group.

[Github Releases: v0.1.2](https://github.com/Heaciy/TabClip/releases/tag/v0.1.2)

## v0.1.1

> 2025-08-13

### ✨ Features

- Browser tab groups: Added support for managing native browser tab groups, which will be stored as independent groups
  in TabClip.

### 🐛 Bug Fixes

- Firefox context menu: Fixed an issue where TabClip's context menus disappeared after restarting Firefox.

[Github Releases: v0.1.1](https://github.com/Heaciy/TabClip/releases/tag/v0.1.1)

## v0.1.0

> 2025-06-14

### ✨ Features

- One-click archive & restore: Instantly save or reopen all your tabs.
- Modern UI: Built with Shadcn-Vue and TailwindCSS for a clean and responsive experience.
- Multi-language support: Currently supports English and Chinese, with more coming soon.
- Light/Dark mode: Customize appearance to your preference.
- Efficient memory usage: Infinite scrolling and timeline display enable fast performance even with thousands of tabs.
- Fast search & filters: Quickly find tabs by keyword, time, or favorites.
- Tab group management: Favorite, lock, delete, copy links, and reorder tabs via drag-and-drop.
- Data import/export: Full metadata support, compatible with OneTab exports.
- Activity visualization: GitHub-style heatmap shows tab activity trends.

[Github Releases: v0.1.0](https://github.com/Heaciy/TabClip/releases/tag/v0.1.0)
