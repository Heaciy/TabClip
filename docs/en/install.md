# Install Extension

Download from the Chrome/Edge/Firefox extension store or download the compiled extension from Github for manual installation.

## Chrome

::: tip
🌟 Click [🔗this link](https://chromewebstore.google.com/detail/tabclip-tab-manager/hncnlhjjpjcdohgcgbjoeogibifmfchf) to go to the Chrome Web Store to download. Thank you for your support.
:::

## Edge

::: tip
🌟 Click [🔗this link](https://microsoftedge.microsoft.com/addons/detail/decldfllagpggbilmhhccehcmcafmmmh) to go to the Edge Add-ons store to download. Thank you for your support.
:::

## Firefox

::: tip
🌟 Click [🔗this link](https://addons.mozilla.org/en-GB/firefox/addon/tabclip-tab-manager/) to go to the Firefox Add-ons store to download. Thank you for your support.
:::

## Github

::: tip
🚀 Click [🔗this link](https://github.com/Heaciy/TabClip/releases) to go to the releases page to download. You can also follow the "Build Guidelines" in the [README.md](https://github.com/Heaciy/TabClip/blob/main/README.md) to download the source code and compile it yourself.
:::
