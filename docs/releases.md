# 更新日志

本页面用于记录 TabClip 所有的版本更新。

## v0.1.2

> 2025-12-09

### ✨ 新功能

- 标签组分类：支持为标签组添加分类管理
- 侧边栏管理：新增侧边栏，方便管理分类
- 标签页白名单：可通过白名单过滤不需要存储的标签页
- 国际化：增加对更多语言的支持，日语、韩语、法语、西班牙语等
- 界面与设置优化：支持恢复默认设置，新增版本说明，并优化界面体验

### 🐛 问题修复

- 重复渲染问题：修复自定义设置后加载第一页数据时出现的多次请求和标签组重复渲染
- 滚动加载错误：修复删除标签组后，滚动加载下一页时数据偏移的问题

[Github Releases: v0.1.2](https://github.com/Heaciy/TabClip/releases/tag/v0.1.2)

## v0.1.1

> 2025-08-13

### ✨ 新功能

- 支持管理浏览器标签页组：支持管理浏览器原生的标签页组，将会作为独立的新分组存储

### 🐛 问题修复

- 修复 Firefox 中的上下文菜单：修复 Firefox 重启后 TabClip 上下文菜单缺失的问题

[Github Releases: v0.1.1](https://github.com/Heaciy/TabClip/releases/tag/v0.1.1)

## v0.1.0

> 2025-06-14

### ✨ 新功能

- 一键归档与恢复： 支持快速收起或恢复所有浏览器标签页
- 现代化界面： 基于 Shadcn-Vue 与 TailwindCSS 构建，界面简洁、流畅、轻量
- 多语言支持： 初始支持中文与英文，并将持续扩展更多语言
- 亮/暗色主题： 可根据偏好在亮色与暗色模式间切换
- 智能内存管理： 内置懒加载策略，即使存储数万个标签页也能保持流畅运行
- 快速搜索与筛选： 支持按关键字、时间等方式快速定位已保存的标签页内容
- 强大的标签组功能： 支持收藏、锁定、拖动排序，并可一键复制分组内全部链接
- 数据导入与导出： 支持从 OneTab 导入数据，并完整保留元信息
- 活动统计图表： 提供 GitHub 风格的热力图，直观呈现标签使用与存储情况

[Github Releases: v0.1.0](https://github.com/Heaciy/TabClip/releases/tag/v0.1.0)
