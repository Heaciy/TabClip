# 插件设置

本页面将对插件中的设置项做出相关解释说明。

## 允许收起固定的标签页

- 默认值/推荐值: 关闭 ❎
- 配置说明: 是否允许收起被固定的标签页，默认不允许，如果配置为允许那么当 TabClip 收起标签页时导航栏中被固定的页面也会被收起，推荐关闭。

## 允许收起浏览器标签组

- 默认值/推荐值: 关闭 ❎
- 配置说明: 是否允许收起浏览器中标签页分组，默认不允许，如果配置为允许那么当 TabClip 收起标签页时浏览器标签页分组中页面也会被收起，每一个标签页分组会作为一个独立的组存储，默认关闭。

## 默认锁定标签组

- 默认值/推荐值: 关闭 ❎
- 配置说明: 新增标签组时默认锁定标签组以屏蔽修改或删除, 默认不锁定，即默认关闭该配置。

## 在新的窗口打开标签组

- 默认值/推荐值: 关闭 ❎
- 配置说明: 新建窗口来打开标签组, 默认在当前窗口打开标签组，即默认关闭该配置。

## 从谷歌加载图标

- 默认值/推荐值: 关闭 ❎
- 配置说明: 当图标没有被缓存时从谷歌在线加载图标，注意该功能需要联网功能。一般情况下只有导入的数据才可能出现缺少图标（因为导入的标签页在当前浏览器可能从未被访问因此其图标未被浏览器缓存），所以默认关闭该配置。

## 作为启动页

- 默认值/推荐值: 开启 ✅
- 配置说明: 每次启动浏览器时自动打开 TabClip 作为首页，默认开启。

## 页面大小

- 默认值/推荐值: 10
- 配置说明: 标签组列表使用滚动加载以减少插件的内存占用，该配置项决定每次滚动时加载的标签组数量，可以不用关注此项配置。
