# 隐私政策

本插件为了实现核心功能，申请了以下权限。我们承诺不会收集、存储或传输任何用户的敏感信息，所有权限的使用仅限于实现插件本身的功能。

### `tabs` 标签页

- 权限说明: 允许插件读取当前浏览器中打开的标签页信息。
- 使用目的: 用于读取当前所有打开的网页链接，实现标签页管理。不用于跟踪用户浏览行为。

### `contextMenus` 上下文菜单

- 权限说明: 允许插件在网页右键菜单中添加自定义菜单项。
- 使用目的: 用于为用户提供便捷的右键操作入口，例如“发送此标签页至 TabClip”或“发送当前窗口全部标签页至 TabClip”等。

### `storage` 存储

- 权限说明: 允许插件使用 Chrome 的本地存储功能。
- 使用目的: 用于保存插件的设置、用户偏好或缓存信息，提升性能和用户体验。数据只保存在本地，不上传至任何服务器。

### `favicon` 网站图标

- 权限说明: 允许插件访问网页的站点图标（favicon）。
- 使用目的: 用于在插件界面中展示对应网页的图标，提升用户体验。例如在标签页列表中显示每个页面的图标。

### `downloads` 下载内容

- 权限说明: 允许插件管理和发起文件下载。
- 使用目的: 用于帮助用户下载插件生成的数据文件（如导出的配置文件），不会进行自动下载或获取用户文件。
