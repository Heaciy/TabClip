# 安装插件

从 Chrome/Edge 插件商城下载或是从 Github 下载编译好的插件手动安装。

## Chrome

::: tip
🌟 点击 [🔗此链接](https://chromewebstore.google.com/category/extensions?utm_source=ext_sidebar&hl=zh-CN) 跳转 Chrome 插件商城即可下载，感谢您的支持。
:::

## Edge

::: tip
🌟 点击 [🔗此链接](https://microsoftedge.microsoft.com/addons/Microsoft-Edge-Extensions-Home?hl=zh-CN) 跳转 Edge 插件商城即可下载，感谢您的支持。
:::

## Firefox

::: warning
🙇 十分抱歉 Firefox 版本的插件正在适配中，敬请期待谢谢您的支持。
:::

## Github

::: tip
🚀 点击 [🔗此链接](https://github.com/Heaciy/TabClip/releases) 跳转 Chrome 插件商城即可下载。也可按照 [README 文档](https://github.com/Heaciy/TabClip/blob/main/README_zh.md)中的 "构建指南" 说明自行下载源码编译使用。
:::
