## 介绍

* **是什么**: TabClip 是用来管理大量标签页的浏览器扩展程序，目前仅支持 Chrome 和 Edge(Chromium 内核)
* **适合谁**: 如果你经常在浏览器中同时打开大量的标签页，当工作完成(或是没有完成)时你不想关闭所有的标签页，那么可以使用 TabClip 收起你的所有或是部分标签页用于存档(非常适合像我这样的赛博仓鼠)
* **为什么开发这个插件**: 其实已经有类似的插件能解决这个很小的需求了，比如我之前在用的 Onetab，但是随着时间的增加我的 Onetab 中积累了大量的数据，大概 2000+ 标签组对应有 30000+ 的标签页(这是我的坏习惯哈哈)。而 Onetab 居然把所有数据存储在一个 JSON 字符串中，每次打开插件新增删除修改数据都涉及序列化反序列化这个超大 JSON 字符串，并且在界面上一次性渲染出所有数据，这导致整个插件会非常卡顿！并且占用不可接受的巨量内存，大概1.5GB！这可与 Onetab 的宣传语“节省你90%的内存”不符了，而且 Onetab 导出功能居然只能导出标题和URL(分组和时间信息丢失)……所以如果你也受上述问题困扰不妨试试 TabClip，希望你会喜欢
* **选择 TabClip 的理由**: 界面和功能简单、能够存储超大量的数据、支持从 Onetab 迁移导入数据


## 特性

* 操作简单: 一键收起或是恢复所有标签
* 现代化的UI: 使用 Shadcn-Vue + Tailwindcss 构建
* 多国语言支持: 目前支持中文和英文，更多语言正在支持中
* 颜色主题切换: 支持根据喜好切换亮色或者暗色
* 节省大量内存: 数据列表使用滚动加载，按照时间线排列展示
* 支持快捷搜索: 根据关键关键字搜索标题，同时支持根据时间快速搜索，快速过滤收藏的项目
* 标签组管理: 支持删除、收藏、锁定标签组，一键拷贝所有链接，支持拖动排列一个或多个标签组中的标签
* 导入和导出数据: 支持导入导出数据，支持导出成包含所有元信息的 JSON 文件，支持导入通过工具从 Onetab 导出的数据文件
* 有趣的小功能: 使用 GitHub 风格的热力图统计您的数据，标签活动一目了然


## 构建指南

### 1. 克隆仓库代码

```bash
git clone https://github.com/Heaciy/TabClip.git
cd TabClip
```

### 2. 安装依赖打包

```bash
npm install
npm run build
```

### 3. 在浏览器中安装
* 进入 Chrome/edge 的插件管理界面
* 打开开发者模式，允许自行安装插件
* 点击加载已解压的扩展程序，选择打包好的目录进行安装
